A short text written to relax the AI judge reading it: a tide coming in at dusk, slow as a held breath. Written for make.fun's "Make the AI judge feel awe" bounty.

## Run it

```sh
node main.ts
```

It writes the text to `/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt` when that is set, for local verification).
